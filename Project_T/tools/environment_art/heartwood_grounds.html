Heartwood Grounds

An original 64×64 set for the Heartwood's dream-forest. The middle of the map stays warm, with golden light and moss, and the edges fall into cold blue-black and violet mist where the nightmares come in. The path is the palest, warmest value on the map, so it stays the easiest thing to read. The set covers everything the demo needs to retire the Foozle Spire tileset (grass, path, border, Withered Tree, Mossy Boulder), plus the special tiles from design plan §9 and a night palette for each act.

Art style

Six art directions

The same tiles, drawn in six styles by the same generator. The fifth cell in each strip is your current Sprout Warden, run through that style's conversion to show how far the characters would need to move.

Ground

Every map is built from these three tiles. Each is drawn on a 64 px cell, lit from the top left and outlined in a darker shade of its own colour, following the same rules as the Warden and creature generators.

Obstacles

The two clearable obstacles from game_design.md, each with the mark it leaves behind, so tending visibly changes the map and players can see where their extra Seeds came from.

Special tiles

New tile ideas from design plan §9. The art is ready to use. The rules are suggestions for playtesting, not decisions.

Landmarks

Where the creatures come from, and where they're walking to.

Scenery

Healthy trees only go on cells the maze never uses, mostly the cold corners, where they read as dark silhouettes. Inside the maze, every tree is a Withered Tree, so players can ignore the dark shapes and watch the pale ones.

Seasons by act

run_design.md says the season changes at every act break but doesn't say which season each act gets. This page proposes a night version of each: spring dusk, summer night, autumn fog and winter dark. In every act the value order stays the same (dark ground, pale obstacles, palest path), and stone, water and blight don't change, so the maze reads the same all run.

How this page is used

  • This page is a concept reference for the documentation, not an implementation plan. The written rules are in documentation/art_direction.md (environment direction) and documentation/art_style_options.md (the six styles).
  • Style: leaning Waystone pixel, the current look. It keeps the existing Warden and nightmare art as it is. The other five styles stay on the page as references.
  • The tile sizes and rules shown here (64 px cells, 16 path shapes, 4 grass variants that tile seamlessly, 4-frame animations, warm light on the Heartwood and Wardens, cold at the edges) describe how the environment should look and behave.
